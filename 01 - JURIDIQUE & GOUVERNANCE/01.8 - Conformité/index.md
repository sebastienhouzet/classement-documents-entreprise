# 01.8 - Conformité

> Chemin : `01 - JURIDIQUE & GOUVERNANCE/01.8 - Conformité`

## À quoi sert ce dossier

Les documents qui prouvent que l'entreprise respecte ses obligations réglementaires transverses : RGPD, conditions générales, politiques internes. Ce sont des documents versionnés : on garde chaque version datée, car un client peut avoir contracté sous une version ancienne.

## Documents à y ranger

- **RGPD** : registre des traitements (fichier vivant + exports datés), analyses d'impact (AIPD), contrats de sous-traitance / DPA signés avec les prestataires, procédure de gestion des violations de données et registre des violations, politique de confidentialité (chaque version datée), mentions légales, désignation du DPO le cas échéant, réponses aux demandes d'exercice de droits
- **CGV / CGU / CGA** : chaque version datée, avec la date d'entrée en vigueur
- **Politiques et chartes** : charte informatique, politique de sécurité, politique de télétravail (versions), charte éthique, procédure d'alerte interne (obligatoire ≥ 50 salariés)
- Obligations sectorielles éventuelles (agrément, déclaration d'activité de formation…)

## Ne pas ranger ici

- Contrats clients signés (qui renvoient aux CGV) → `02.1`
- Charte informatique signée par chaque salarié → dossier du salarié `03.2`

## Méthode de classement

Trois sous-dossiers : `RGPD`, `CGV-CGU`, `Politiques et chartes`. Dans chacun, fichiers nommés `AAAA-MM-JJ_CGV_v3.pdf` ; le fichier en vigueur peut être dupliqué sous le nom `CGV-en-vigueur.pdf` pour être trouvé immédiatement.

## Durée de conservation

| | |
|---|---|
| **Minimum légal** | CGV : 5 ans après la fin du dernier contrat conclu sous cette version (10 ans pour les contrats électroniques ≥ 120 €). Registre RGPD : à tenir à jour en permanence. |
| **Recommandé** | Garder toutes les versions des CGV/CGU pendant 10 ans après leur remplacement. Versions du registre RGPD : 5 ans. |

Base : RGPD art. 30 et 28 ; Code de la consommation art. L.213-1 ; Code civil art. 2224.
